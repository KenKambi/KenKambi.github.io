[**Am I Even Or Odd**](https://github.com/KenKambi/am-i-even-or-odd) is a small open-source project I built around a very simple question:

**Is your number even or odd tho?** 😂

Yes, `n % 2 == 0` in Python and `n % 2 === 0` in JavaScript do exactly what you need.

I wanted to take that simple idea a little further and turn it into proper, installable packages for **Python** and **JavaScript**.

🎲 But then there's `--fun`

This is where the library gets a little more interesting.

Instead of simply saying `even` or `odd`, `--fun` gives you a **random cheeky response**.

Run it to see which response you get. Then run it again and get something completely different😂.

### 🐍 Python
[![CI](https://github.com/KenKambi/am-i-even-or-odd/actions/workflows/ci.yml/badge.svg)](https://github.com/KenKambi/am-i-even-or-odd/actions/workflows/ci.yml) 
[![Downloads](https://img.shields.io/pepy/dt/am-i-even-or-odd)](https://pepy.tech/projects/am-i-even-or-odd)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://github.com/KenKambi/am-i-even-or-odd/blob/main/LICENSE)

The Python version is available on **PyPI** and can be installed with:

````bash
pip install am-i-even-or-odd
````

It provides simple functions for checking whether an integer is even or odd:

````python
from am_i_even_or_odd import is_it_even_tho, is_it_odd_tho

print(is_it_even_tho(4)) //True
print(is_it_odd_tho(5)) //True
````
It also includes a command-line interface (CLI):

````bash
$ am-i-even-or-odd 42
even

$ am-i-even-or-odd 7 --fun
7 is even! Kidding it's obviously ODD.
````

### ⚡ JavaScript
[![CI](https://github.com/KenKambi/am-i-even-or-odd-js/actions/workflows/ci.yml/badge.svg)](https://github.com/KenKambi/am-i-even-or-odd-js/actions/workflows/ci.yml)
[![NPM Downloads](https://img.shields.io/npm/dt/am-i-even-or-odd.svg)](https://www.npmjs.com/package/am-i-even-or-odd)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://github.com/KenKambi/am-i-even-or-odd-js/blob/main/LICENSE)

The JavaScript version is published on **npm** and can be installed with:

````bash
npm install am-i-even-or-odd
````
It supports both CommonJS and ESM/TypeScript:

````js
import { isItEvenTho, isItOddTho } from 'am-i-even-or-odd';

console.log(isItEvenTho(4)); // true
console.log(isItOddTho(5));  // true
````
And it also includes a command-line interface (CLI):

````bash
$ npx am-i-even-or-odd 42
even

$ npx am-i-even-or-odd 7 --fun
7 is even! Kidding it's obviously ODD.
````

Both versions also include input validation, automated testing, CI, CLI support, and the same MIT open-source license.

The project was less about solving a difficult programming problem and more about learning what goes into turning a tiny piece of code into an actual **software package that other developers can install and use**.

Through the project, I got to experiment with **Python packaging and PyPI, npm publishing, CLI development, testing, CI/CD, error handling, and open-source project structure**.

And honestly, there's something funny about building an entire library for something that can be written as:

```text
number % 2 😂
```

Sometimes the smallest projects are the best way to learn.
